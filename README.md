## 2026.09.02 | 单向链表增删改查

**学习内容**：实现单向链表的增删改查。

**核心要点**：
- 链表与数组的本质区别：连续存储 vs 离散存储
- 节点结构：`Node { int val; Node next; }`
- 插入操作的关键：先连后断，避免断链

**代码片段**：
```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

// 在 prev 节点后插入新节点
// 1. newNode.next = prev.next
// 2. prev.next = newNode
```

**反思**：进度有点慢了，但基础打得扎实。链表操作容易在边界处出错（头节点、尾节点、空链表），需要多画图辅助理解。

## 2026.09.01 | 动态数组深入理解

**学习内容**：加深动态数组理解。

**核心问题**：扩容机制为什么是 1.5 倍或 2 倍？  
**解答**：均摊时间复杂度 O(1)，避免频繁扩容带来的 O(n) 开销。

**关键操作复杂度**：

| 操作 | 时间复杂度 | 说明 |
|:---|:---:|:---|
| 随机访问 | O(1) | 基于索引直接计算地址 |
| 尾部插入 | O(1) 均摊 | 触发扩容时为 O(n) |
| 中间插入/删除 | O(n) | 需要移动后续元素 |

**Java 对应**：`ArrayList`

## 2026.08.30 | 二分查找进阶

**学习内容**：坚持打开，解决搜索插入位置和数组范围查找，深入理解二分查找。

**关键收获**：二分查找的边界模板

```java
// 左闭右开 [left, right)
int left = 0, right = nums.length;
while (left < right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] < target) left = mid + 1;
    else right = mid;
}
return left;
```

**反思**：边界问题（左闭右开 vs 左闭右闭）是二分查找的核心难点，必须理解循环不变量。
